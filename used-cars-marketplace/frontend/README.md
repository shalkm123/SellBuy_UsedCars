# Frontend (SellBuy Used Cars)

Use the root project guide for full setup: [../README.md](../README.md)

Quick start for frontend only:

```bash
pnpm install
pnpm run dev
```

Default app URL: http://localhost:5173

Required env file:

Create `frontend/.env`:

```env
VITE_API_URL=http://localhost:8080/api
```
